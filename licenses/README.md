# Third-party notices

The execution used installed open-source dependencies. Their available license notices are retained here, together with TypeScript's third-party notice. `manifest.json` records the installed Python package versions and copied notice paths. Dependency distributions and binaries are not vendored; obtain exact releases through the documented public retrieval commands.

Original code is MIT-licensed under the root `LICENSE`. Retained Vite source in `evidence/upstream/vite/` is covered by `Vite-LICENSE.txt`; MkDocs source and excerpts in `evidence/upstream/mkdocs/` by `MkDocs-LICENSE.txt`. The IEEE class and bibliography style retain their original notices in the paper directory of the complete bundle.

Dependency notices govern their corresponding distributions and are not replaced by the original-code license.

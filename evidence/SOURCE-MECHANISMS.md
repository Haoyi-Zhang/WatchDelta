# Source and mechanism evidence

## Runtime implementations

The bundle pins and records the source or installed artifact used for TypeScript 5.8.3, watchfiles 1.2.0/notify 8.0.0, Uvicorn 0.48.0, Hypercorn 0.18.0, Python, Node.js, and supporting packages. Hashes and environment metadata are stored under `evidence/` and each dataset.

## Vite output-directory decision

The Vite replay executes a JavaScript transcription of the relevant tagged source decision from 5.2.4 and 5.2.10 on a bounded absolute-path matrix, with source guards. It verifies the reported `emptyOutDir=false` boundary but does not execute the tagged TypeScript function or claim full Vite/Rollup/Chokidar execution.

## MkDocs build-loop batching

The MkDocs replay executes the merged `_build_loop` scheduling mechanism with callbacks injected after observer acceptance. It checks batching, spacing, build-function identity, and events arriving during an active build. It does not claim complete watchdog, renderer, or browser-live-reload execution.

## Reference-cache isolation

The excluded pilot imported the measured terminal module to construct a nominally clean reference. Equal source length and restored timestamp metadata could satisfy bytecode validation and execute stale cached code. The corrected reference reads and compiles copied terminal bytes in a fresh interpreter with bytecode writing disabled. The retained pilot and regression test are the direct local evidence; PEP 3147 and PEP 552 provide specification context.

## Adaptive diagnosis

The adaptive layer declares six boundaries, enumerates a finite hypothesis space, predicts a lifecycle/output signature for each repair–hypothesis pair, and updates the candidate set after each actual-process execution. The planner minimizes the largest surviving bucket, then aggregate bucket concentration and repair breadth. An observation predicted by no remaining hypothesis yields `unmodeled` rather than a forced label.

The execution adapter uses the seeded fault set and selected repairs to construct each replay with named faults omitted. Only the planner is truth-blinded. Those replays measure discrimination under oracle-driven repair semantics. In the separate `local_unknown.py` comparison, the repair routine instead sends literal selector/root configuration changes to an existing process. Qualification rejects failed reference/readiness/capture premises before either signature mapping or panel decoding; an inconclusive episode is not a correctable signature substitution.

## Distance-constrained panel synthesis

The panel compiler treats each hypothesis signature as a codeword over the intervention catalog. A binary multicover formulation requires every pair of hypotheses to differ in at least `2e+1` selected coordinates for an error budget `e`. SciPy's HiGHS MILP backend minimizes panel cardinality and then intervention cost/breadth. A separate certificate recomputes all pairwise distances, and the decoder emits an exact hypothesis only when it is uniquely within the declared Hamming radius. The retained study executes the synthesized panel rather than validating only symbolic signatures.

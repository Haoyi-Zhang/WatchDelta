## Negative and excluded evidence

The retained Hypercorn oracle pilot imported the measured module to construct the reference. Restored timestamp metadata allowed stale bytecode reuse, so a stale server and stale reference agreed. The corrected oracle copies final source bytes, disables bytecode writing, and compiles the copied bytes directly. The pilot remains under `results/pilots/hypercorn-oracle-contamination` and is excluded from formal counts.

## Audit rule

Every formal runtime dataset has a frozen protocol, completion marker, per-episode record mirror, endpoint projection, and analyzer. `evidence/source-revision-audit.json` records the executable source used for analysis without rewriting archived experiment records.
